# Totem Bar Binds

Keybinds for the shaman totem bar in WoW Classic Forever.

The default totem bar's buttons can't be bound through the normal Keybindings menu. This addon lets you bind:

- Call of Totems
- Totem slots 1–4 (the totems on the currently selected Call page)
- Totemic Recall

## Usage

Open the settings with the minimap button or `/tbb`.

- **Left-click** a row, then press a key (Shift, Ctrl and Alt combinations work).
- **Right-click** a row to clear it.
- **Esc** cancels.

Drag the minimap button to move it around the minimap.

## Notes

- Binds can't be changed in combat (a game restriction).
- If you switch the Call page in combat, the slot keys follow the new page once combat ends.
